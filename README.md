# dsh-clock

DSH 插件：**让 AI 知道现在几点。**

## 为什么需要它

AI 分不清「下午五点」和「凌晨五点」，于是会说「夜深了，早点睡」——而对面可能刚吃完午饭。

这个插件给模型三个工具，让它开口前先看一眼钟。

## 工具

| 工具 | 作用 |
|---|---|
| `clock_now` | 本地时间、星期、**时段**、今天过了多少、**该怎么开口** |
| `clock_until` | 距离某个时刻还有多久（如「还有 5 小时 46 分钟到 23:00」） |
| `clock_diff` | 两个时间点差多久 |

`clock_now` 返回里有一个 `hint` 字段，是给模型的口吻建议：

```
早上  → 说「早」比说「晚安」对
下午  → 别用「夜深了」「早点睡」这类话
深夜  → 别硬聊，问一句要不要睡
```

## 安装

```bash
dsh plugin --profile desktop add dsh-clock
```

无配置、无依赖、无网络请求。

## 输出示例

```json
{
  "local": "2026-10-25 17:14:19",
  "weekday": "星期五",
  "period": "傍晚",
  "timezone": "Asia/Shanghai",
  "utc_offset": "+08:00",
  "day_progress": "72%",
  "minutes_left_today": 406,
  "hint": "傍晚。快到饭点了。"
}
```
